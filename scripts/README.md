# Scripts

This folder contains the analysis scripts for the linear programming alloy screening workflow.

## Sections

- `01_lp_flare/`: LP-FLARE validation, comparison, and diagnostic plotting.
- `02_high_throughput_screening/`: Scripts that generate or enumerate high-throughput alloy screening results.
- `03_filtering_candidate_alloys/`: Scripts for filtering survivor sets and selecting candidate alloys.
- `04_elm_analysis/`: Scripts for ELM-related analysis.

## Data policy

Large CSV outputs are intentionally not tracked in this repository. Keep full calculation outputs in the local calculation workspace unless a small curated file is needed for reproducibility.
