# LP-FLARE

Scripts for LP-FLARE validation, comparison, and diagnostic plotting.

## Files

- `plot_lp_parity.py`: Compares LP survivor outputs with brute-force FLARE survivor outputs and writes parity plots.

## Current data assumptions

`plot_lp_parity.py` expects the LP and brute-force survivor CSV files to be available in the working directory used when running the script.
