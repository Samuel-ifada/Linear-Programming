# Linear Programming

Repository for the linear programming alloy screening manuscript and supporting analysis scripts.

## Repository structure

- `manuscript/`: Overleaf-compatible LaTeX manuscript source.
- `scripts/`: Python scripts used for screening and plotting.
- `figures/`: Manuscript figures intended for version control.
- `data/`: Placeholder for local input data. Large datasets and generated calculation outputs are not tracked.

## Notes

The calculation workspace is kept outside this repository. Copy only curated scripts, manuscript files, and publication-ready figures into this repo.

## Scripts

- `scripts/01_lp_flare/`: LP-FLARE validation and parity plotting.
- `scripts/02_high_throughput_screening/`: LP grid generation and high-throughput screening.
- `scripts/03_filtering_candidate_alloys/`: Candidate alloy filtering workflows.
- `scripts/04_elm_analysis/`: ELM-related analysis workflows.
